VERSION PUBLICA PARA GITHUB PAGES
No incluye datos personales, respuestas ni enlace de la encuesta.
Sube index.html, app.js, icon.svg, manifest.webmanifest y sw.js a la raiz del repositorio.
Configura Settings > Pages > Deploy from a branch > main > / (root) > Save.
En el enlace publicado, escribe el enlace de Forms y tus datos y pulsa Guardar datos.
Los datos se guardan en localStorage del navegador, no en GitHub. No borres los datos del sitio si quieres conservarlos.
Esta PWA NO rellena ni envia automaticamente Microsoft Forms.
